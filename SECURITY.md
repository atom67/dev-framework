# Security

No private vulnerability-reporting channel is configured for this repository.
Do not include secrets, credentials, or private project data in a public issue.

Until a channel exists, a report that cannot be made public has no supported intake here.
Opening that channel is a repository setting, not a promise made by this file.

What the package does with files, network, and checks is in [README.md](README.md#security-and-scope).
The secret scan is a text heuristic. It is not a security audit.
