## Trimming rule

After the operator accepts a piece of work, cut this file back to:

- everything active,
- the next agreed items,
- **the three most recently finished features**, as a reminder of what just changed.

Nothing else. This file has grown to 167 KB before, at which point nobody read it and it
stopped steering anything. Keep it under 80 KB; if it is approaching that, it needs
trimming, not a bigger limit.
