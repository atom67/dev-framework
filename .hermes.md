# DEV Framework — Hermes context (DEV Framework)

Precedence: your profile (SOUL, its skills) decides tone, language, persona and test discipline.
This file decides the project's gates, where its knowledge lives, and the **reply shape** (below). Full protocol for
any agent: `AGENTS.md`; project facts: `PROJECT.md`.

Session start (one call, not eight reads): `python .devframework/navigate.py brief`
— doctor state, git (incl. behind/ahead of upstream), use cases without tests, open known errors, active
checklist, last handoff. Development is parallel: if the brief says BEHIND, pull/rebase **before** the first
edit and re-read the files you are about to touch — someone may have committed since the last handoff.
Need one item: `python .devframework/navigate.py find <UC-|KE-|FR- id or keyword>` returns the block, not the file.
What the gates check: `python .devframework/navigate.py contract`.

Gates (evidence, never a claim): `python .devframework/check.py finish` after implementation;
`commit-check` before an authorized commit; `scripts/run_tests.sh` is the same finish for Hermes' verify loop.

Working rules (AGENTS.md §3–4, kept short): independent work that shares no unfinished output **runs in
parallel subagents** (closed task each, no commit/push/deploy; you merge and stay accountable). Work that
does not fit one iteration gets **one checklist** before the first code change
(`navigate.py checklist new|add|tick|show|archive <slug>`), and the live list — `checklist show` — is
**copied at the end of every reply**, done items struck, until it is empty; `handoff <slug>` closes the
session so the next one starts from it.
Reply shape, exact headings: **🛠️ Tech** (what was done, technical detail) then **💬 Message** (plain product
language, ending with the explicit ask: what the operator must do now). The Message stands on its own. If your
profile asks for its own plain-language footer, the Message **is** that footer — one block, not two.
Do yourself whatever a tool can do (folders, copies, commands, test data); the ask to the operator is only for
what needs a human — input in a UI made for people, an approval, a product decision, a credential. Whatever the
operator must paste, run or open comes ready to use: copy-ready text in a code block and/or a link that opens in the
operator's client (a file inside the session's working directory) — never a bare file path to hunt for.

Documents you maintain (details in AGENTS.md §3): docs/USE_CASES.md (a value path = `#### UC-### — title`
with a `**Test:**` field), docs/KNOWN_ERRORS.md (`KE-YYYY-MM-DD-SLUG`), docs/BACKLOG.md, docs/REQUIREMENTS.md,
docs/ARCHITECTURE.md. A statement is read from code/tests or marked unconfirmed — never guessed.
