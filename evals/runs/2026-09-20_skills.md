## Findings about the framework as a Hermes *skills* product
1. **Hub install is dead on arrival.** `hermes skills install trenthalden/dev-framework/skills/catch-up` → skills-guard verdict
   DANGEROUS: rule `agent_config_mod` fires on every mention of `AGENTS.md`/`CLAUDE.md` (CRITICAL persistence ×4) and
   `allowed_tools_field` on the Claude-style `allowed-tools:` frontmatter (LOW). `--force` cannot override. A framework
   whose job is to write AGENTS.md will always trip this rule → **skills-as-distribution cannot work via the hub**;
   all three agents fell back to copying the directory into `$HERMES_HOME/skills/`. `import-dev-framework` additionally
   failed with `Could not fetch` on skills.sh (raw GitHub URLs are fine, so it is the index, not the repo).
2. **Installer rejects the scenario scale string** `"1 user (personal tool)"` — my prompt bug; also a UX ceiling: novices
   will type free text there. Accept anything with a leading integer, or drop the unit requirement.
3. `finish` needs an existing Git repo (`rev-parse --show-toplevel`) but README/VERIFICATION say it works "before first
   staging" — S1 lost a cycle on that. Doctor's "padded IDs" wording was misread once.
4. Skill text conflicts with the task: `catch-up` says "not from the README", S2/S3 require folding README/notes in.
   Every agent noticed and treated the prompt as the override — the skill needs a "notes are sources, cite them" clause.
5. Cost audit and "plant a timer" checks are manual greps; secrets/doctor plants have commands. Uneven.
6. Hermes-specific: git-bash `/d/...` vs `D:\` path confusion cost S3 its first two turns (clone "vanished").
7. Framework docs + skills read ≈ 5–6 tool calls and ~40–50k input tokens before the first project action in every run.
   That is the fixed cost a plugin must cut (bundle README/SKILL essentials into one tool description).

Verdict for the skills variant: **works, quality high, distribution blocked by the security scanner.** The plugin
variant is therefore not optional — it is the only installable form.
